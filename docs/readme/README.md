# README artwork and screenshots

The banner is original Jotley vector artwork created for this source release. The native product screenshots use example notes and show Mac, iPhone and iPad. The mobile captures were taken from the current iOS/iPadOS 27 simulator builds using the existing App Store screenshot test. The Mac capture was retained from the native Jotley marketing capture. Their pixels were copied without edits; they are screenshots, not generated interface mockups.

| File | Contents |
| --- | --- |
| `banner.svg` | Original purple Jotley banner and waveform illustration. |
| `mac-summary.webp` | Native Mac app, note list and a saved summary in dark mode. |
| `iphone-transcript.png` | Timestamped transcript on iPhone. |
| `iphone-summary.png` | Saved summary on iPhone. |
| `ipad-organized.png` | iPad note list beside an organized summary. |

These captures are documentation assets and are not application resources. They illustrate the product; the README does not claim that every newly added control is visible in these saved-note captures. Jotley's original documentation/artwork uses its [source-available license](../../LICENSE); third-party marks keep their separate rights.
