# Responsive onboarding artwork — October 22, 2026

The final design uses the original detailed illustrations on every platform. iOS assets are byte-for-byte copies of the original Mac artwork. The separately generated simplified icons and duplicate `-large` catalogs were removed from the project at the owner's request.

Compact phone/folded Duo artwork remains beside the heading: 88 points with the regular large title, or 68 points with the denser title, scaling with Dynamic Type. iPad and unfolded Duo use the same originals at 240–300 points. Folding changes the layout without resetting setup state. The mobile footer keeps its 12-point bottom padding and fixed reserved Not now row.

The original artwork generation prompts are preserved in `docs/design/onboarding-art.md`. No new artwork was generated for this change. Earlier generated files outside the project remain archival working material and are not bundled in the app.
