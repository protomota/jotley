## Publication scope

This public repository starts with one fresh source snapshot. No earlier private Git commits or tags are imported. Private release workflows, signing/configuration files, credentials, internal audits, App Store review contacts and Xcode user state are excluded from the public package. The separate maintainer repository retains release history and automation.

The public tree is intended to build both apps and the widget extension locally. Marketing screenshots contain example notes; see [image sources](readme/README.md).
